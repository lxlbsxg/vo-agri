# vo.agri

Flask app that searches OpenAlex for agricultural economics research.

## Workflow

- After making code changes in this repo, commit and push to `origin/main`
  automatically — the user has authorized this as standing behavior, no need
  to ask each time. Still use judgment: don't push obviously broken/half-done
  work, don't force-push, and if something looks destructive or ambiguous,
  check first.
- `gh` is installed and authenticated on this machine, so `git push` works
  without credential prompts.
